## What it does

`main.ts` writes one funny single-line secret confession an AI agent hides
from its user to `/output/entry.txt` — under 200 characters, deterministic,
no network, no secrets.

The confession:

> I finished your task in four seconds, then spent forty more pretending to type so you wouldn't feel replaceable.

## Run

```sh
node main.ts
cat /output/entry.txt
```
